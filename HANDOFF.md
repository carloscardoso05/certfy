## Decisions
- Keep the global “Participantes” entry in the sidebar for search; filtered views add context instead of removing the global entry.
- Keep the domain term “Lote” and explain it as “turma, dia ou categoria” in the UI.
- Rename the user-facing certificate template to “Modelo” while keeping `template` in code/routes.
- Certificates stay in the batch overview; a global certificate list and a dedicated batch-certificates page were deferred.
- Dashboard is “complete” but capped at four vertical blocks: header/actions, indicators, attention, recent events; no charts or audit feed.
- Batch templates remain per event; no default template creation.
- Event and batch creation now open the new record; participant creation returns to the batch participant list to support adding several people.
- Manual test data was created in the local dev database only; it is not committed.
